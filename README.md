# CWSync for KOReader

Standalone fork of Calibre-Web NextGen's `cwngsync.koplugin`, focused on preserving Calibre-Web NextGen shelf order in native KOReader Collections.

Upstream source: `new-usemame/Calibre-Web-NextGen/koreader/plugins/cwngsync.koplugin`.

This plugin is intended to replace `cwngsync.koplugin`, not run alongside it.
